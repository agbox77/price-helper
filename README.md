# 🎯 Помощник определения цен

Одностраничное веб-приложение для расчёта цен на услуги по принципу:

**Регулярное занятие < Пакет < Мастер-класс**

## Принцип работы

1. Все цены приводятся к **цене за 1 час**.
2. Если известна только одна цена — остальные рассчитываются по коэффициентам.
3. Цена пакета зависит от количества модулей:
   - 1 модуль → равна цене МК
   - 2 модуля → скидка (по умолчанию 5%)
   - 3 модуля → скидка (по умолчанию 10%)
4. Фактически введённые цены имеют приоритет над расчётными.
5. Результат округляется до 10 ₽ и выгружается в `.xls`.

## 🔗 Демо

Открыть: `https://<ваш-логин>.github.io/price-helper/`

## 🚀 Запуск локально

Просто откройте `index.html` в браузере — никаких сборщиков не требуется.

## 📄 Структура

- `index.html` — разметка
- `style.css` — стили
- `script.js` — логика расчёта и экспорта

## 🛠 Настройка

Коэффициенты и скидки задаются прямо в интерфейсе и не сохраняются между сессиями.
Если нужна постоянная настройка — измените значения `value` в `index.html`.
